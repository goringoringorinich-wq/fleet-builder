# Конструктор флота

Сборщик ростеров для настольного морского варгейма: каталог соединений всех фракций,
их правила, синергии флота и подсчёт очков.

**Открыть:** https://goringoringorinich-wq.github.io/fleet-builder/

Одна страница, никакого сервера. Работает и без интернета: сохраните её к себе
(Ctrl+S) и открывайте файлом — ростеры хранятся в самом браузере.

## Что здесь лежит

Только собранная страница. Исходники — таблица фракций, разборщик и шаблон — живут
отдельно; сюда попадает готовый файл, и обновляется он вместе с выпуском версии игры.

Страница закрыта от поисковиков (`robots.txt` и `noindex`): она открыта по ссылке,
но специально её не найдут.
